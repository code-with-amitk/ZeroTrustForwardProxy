== Flow
=== Chromium Browser to Upstream
- Remote Chromium browser executes the webpage inside an isolated environment, and the client receives a safe representation of the rendered webpage.

== Pixel rendering in Chromium
- Frame is a vast grid containing millions of pixels side-by-side
- For example, a 1920x1080 frame holds 2,073,600 individual pixels
```
Origin
Server --HTML/CSS--> |Chromium|--> DOM Layout      --> |Compositing Pipeline| --> Rendered Frames
                                 Paint operation                                     |
                                                                                    \/
                                                                                |Encoder H264|
                                                                                    |
                                                                                    \/
                    |User's Browser|<-video stream----|streaming gateway|<--- Video stream
                   local browser decodes the video stream
                   display it video canvas
```
- Rendering: Chromium converts HTML/CSS into DOM, layout and paint operations, then produces rendered frames using its rendering/compositing pipeline.
- Frame capture: A capture component obtains the rendered frames from Chromium's compositor or virtual display.
- Video encoding: An encoder such as H.264 or VP8 compresses the frames into a video stream. Hardware GPU encoding can help where available.
- Streaming: A streaming gateway sends encoded frames to the user's browser, commonly using WebRTC or another suitable low-latency transport.
- Client rendering: The local browser decodes the video stream and displays it, typically inside a video/canvas surface.

== Scaling RBI
```

```
**For Scaling**

- Multiple RBI worker containers running
- LB will Distribute new sessions based on CPU, memory, GPU utilization and active-session count
- Maintain session affinity: once John is assigned to Worker A, his mouse and keyboard events must continue reaching that same session.
- Horizontally scale the workers
